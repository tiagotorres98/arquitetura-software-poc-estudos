### EXPERIMENTO 2: Arquitetura de CSS com BEM e SASS
* **Conceito**: Padronização e organização de estilos no front-end [29].
* **Objetivo Mínimo**: Evitar colisões de nome de classe e heranças indesejadas de CSS utilizando style-guides [29, 59].
* **Escopo da POC**:
  * Criar uma página HTML simples com 1 componente reutilizável (ex.: um Botão ou Card de informação) [24, 60].
  * Aplicar a convenção **BEM (Block-Element-Modifier)** para mapear os elementos e estados (ex.: `.button`, `.button__icon`, `.button--disabled`) [59, 60].
  * Utilizar **SASS** para organizar variáveis globais de cor e aninhamento (*nesting*) [61].
* **Entregável no GitHub**: Arquivo de estilos SASS estruturado e compilado demonstrando o padrão BEM limpo.
# O que entendi:
> <p>O CSS (Cascading Style Sheets) é uma estrutura utilizada para estilização dos componentes do HTML. O CSS puro permite que o desenvolvedor selecione o componente do HTML por nome de componente, identificacao (id) ou por classe (class) e adicione a estilização programada. Os componentes podem ser repetidos, classes podem ser declaradas em vários componentes diferentes ao mesmo tempo, porém os IDs devem ser únicos para cada componente declarado.</p><p>O BEM (Block, Element, Modifier) é uma metodologia para nomenclatura de classes CSS. A construção é a seguinte: <ul><li>Block: é o componente principal e indenpendente da interface. Ele depende somente da estrutura básica do HTML a nomenclatura da classe é "." + nome da classe. Exemplo: ".btn".</li><li>Element: é o componente que depende de um componente Block. sua nomenclatura vem após a classe principal utilizando dois underscore. Exemplo ".btn__icon"</li><li>Modifier: é o modificador do block ou do element. recebe na nomenclatura "--". Exemplo: ".btn--blue"</li></ul> Assim uma classe pode receber vários dessas nomenclaturas criadas. Exemplo: class="btn btn--blue" e no icone dentro de btn: class="btn__icon"</p><p>O SASS (Syntactically Awesome Style Sheets) é um pré processador de CSS. Isso permite escrever arquivos "CSS mais complexos" podendo adicionar variáveis, aninhamento de classes, funções e outros recursos. Os navegadores não sabem interpretar o SASS, então é necessário que o projeto que o implementa precise passar por um build para gerar os arquivos compatíveis com o navegador..</p><p>
